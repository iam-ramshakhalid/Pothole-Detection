# Pothole Detection

AI course project at FAST-NUCES, Lahore. We detect potholes in dashcam images and video with YOLOv8, so road authorities can see which roads need repair first.

**Team:** Muhammad Talha, Ramsha Khalid, Zuhar Faisal, Kashif Abbas

## Dataset

[Pothole detection YOLOv8](https://universe.roboflow.com/gerapothole/pothole-detection-yolov8) by GeraPotHole (Roboflow Universe), CC BY 4.0. One class: `Potholes`. The dataset is downloaded in the notebook and is not stored in this repo.

## Files

- `F26-1.ipynb`: data preparation notebook (Google Colab)
- `F26-1.pdf`: Deliverable 2 report

## Running the notebook

1. Open `F26-1.ipynb` in Google Colab.
2. Add your Roboflow API key as a Colab secret named `ROBOFLOW_API_KEY`.
3. Run the cells from top to bottom. Run the cleaning cells only once.
